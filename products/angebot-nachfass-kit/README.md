# Angebot-Nachfass-Kit

Vier lokale, kopierbare Vorlagen für das Versenden, sachliche Nachfassen, Umfangs-Rückfragen und freundliches Schließen eines Freelancer-Angebots.

Die Vorlagen enthalten bewusst keine Erfolgs- oder Antwortgarantien und müssen gegen den eigenen Leistungsumfang geprüft werden.
