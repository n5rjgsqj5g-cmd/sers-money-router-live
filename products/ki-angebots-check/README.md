# KI-Angebots-Check v1.0.0

Ein kompaktes Arbeitskit für Freelancer, Solo-Selbstständige und kleine Teams, die ihr Angebot verständlicher machen wollen.

## Schnellstart

1. Öffne `workbook.html` im Browser. Es funktioniert ohne Installation und ohne Internetzugang.
2. Bewerte die zehn Prüffelder ehrlich mit 0, 1 oder 2 Punkten.
3. Bearbeite nur den schwächsten Bereich.
4. Nutze den passenden Prompt aus `prompt-bibliothek.md`.
5. Arbeite den Ablauf in `30-minuten-plan.csv` ab.

## Dateien

- `workbook.html` – interaktiver Score und Copy-Generator
- `scorecard.csv` – Prüffelder für Excel, Numbers oder Google Sheets
- `prompt-bibliothek.md` – sieben Copy-Prompts
- `landingpage-blueprint.md` – schlanker Aufbau für eine Angebotsseite
- `30-minuten-plan.csv` – umsetzbarer Zeitplan
- `LIZENZ.txt` – Nutzungsbedingungen
