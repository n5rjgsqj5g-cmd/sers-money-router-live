# Freelancer-Angebotsvorlage

Kostenlose, lokale Angebotsstruktur für Freelancer. Enthalten sind eine kopierbare HTML-Vorlage, ein Faktencheck und ein Prompt für eine kritische Überarbeitung.

Die Vorlage prüft keine rechtliche, steuerliche oder vertragliche Vollständigkeit. Nutze ausschließlich eigene, belegbare Fakten und füge keine vertraulichen Kundendaten in externe KI-Systeme ein.
